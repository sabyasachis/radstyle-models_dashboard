How to read this dashboard Research only

ID/OOD follows the selected test catalog: ID = persona ranks 1–40; OOD = ranks 41–50. Evaluating a model on the other dataset does not change this label here. A separate badge identifies cross-dataset models. Base-model pretraining exposure is unknown.

Scores: GREEN measures reference-relative clinical agreement; Style measures agreement on applicable style features; ROUGE-L measures wording overlap; Checks are deterministic reference-relative rules. All scorers compare Impressions only, not Findings. GREEN and Style show mean ± sample SD across three calls to the same judge, not a confidence interval.

Decoding: this is the original experiment: non-thinking temperature 0.7, top-p 0.8, presence penalty 1.5; thinking 0.6 / 0.95 / 1.5; top-k 20 in both. These are not Qwen's recommended text settings. The recommended-text follow-up is not mixed into this release. Trained thinking models are excluded.

Public data: the owner approved these non-identifying, open-dataset-derived records for public release. Underlying source terms still apply. Raw reasoning, judge responses, source-record identifiers, and patient metadata are not published. This site is not a clinical decision tool.
