# Data release notice

The repository owner approved public distribution of the non-identifying clinical text on September 21, 2026 and confirmed that the experiment's data derives from open datasets.

On September 24, 2026, the owner requested a persona-token-conditioned report-generation tab. Its reference cohort is checked against the existing approved release before export. The new tab adds the completed experiment's model-generated Impressions, scores, atomic input-token strings and dataset/persona exposure labels; it does not add new source reports or publish persona policies.

The source families are **CT-RATE, MR-RATE, and REXGradient**. This site displays the experiment's supplied Findings and synthetic reference Impressions, alongside model-generated Impressions. Availability here does not grant new rights over the source material or remove upstream attribution, noncommercial, or other license requirements. Consult the original source terms before redistribution or reuse.

The application exports only explicitly selected fields. Original record identifiers, patient/study metadata, private paths, persona policies, model scratchpads and judge response text are omitted. Public report numbers are dashboard display IDs.

This static site and its JSON files are public and downloadable. It has no analytics, external model calls, or user-upload facility. No clinical deployment or patient-care use is intended.
